The data present in this folder will contain SEM micrographs, EDS analysis results and GD-MD results allowing to understand the shape and chemical composition of powder materials (Aluminium Silicide, hypereutectic aluminium silicide alloys)

Each alloy studied will be atributed  trigram depending on the chronology of analysis, this trigram is my initial ARP, and the number of the alloy. i.e: ARP001 is related to AlSi40 produced by ELKEM.

Each analysis performed on these alloys will be named as follow: Trigram+ name of analysis +date+number of the analysis

ie: ARP001-SEM-12-12-2025-1
